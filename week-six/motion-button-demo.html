Duration & easing choices
  • Hover 150ms / press 100ms: hover eases out (decelerates into the lift), press eases in (snaps down) — opposite curves so they read as opposite gestures, not one tween reversed.
  • Content cross-fade 200ms, cubic-bezier(0.4,0,0.2,1): two absolutely-stacked layers swap opacity + a small translate only — the button's box never resizes, so nothing else on the page reflows.
  • Spinner 700ms linear, infinite: linear on purpose — an eased spinner has nothing to accelerate toward, so easing it just looks broken.
  • Success check 320ms, cubic-bezier(0.34,1.56,0.64,1): slight overshoot ("back-out") so it feels rewarding, not just correct.
  • Error shake 420ms ease-in-out: short and sharp — registers as deliberate feedback without delaying the "Retry" label.
  • Reduced motion: toggle above simulates prefers-reduced-motion: reduce live. Color and label changes stay instant; only the glide/spin/shake/pop are removed.
